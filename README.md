# HelpingHeart Marketplace\n\nResponsive OLX-style classifieds application for India.\n\n## Implemented in this first build\n- Search listings, filter by category and condition, sort by price or newest.\n- Firebase email/password registration and sign-in when configured.\n- Create listings with details, price, city and up to four photos.\n- Upload photos to Firebase Storage and save listings in Firestore.\n- View listing details, send a seller message record, view own listings and delete own listings.\n- Preview mode clearly indicates that Firebase is not connected; it does not create shared listings.\n\n## Firebase setup later\n1. Create Firebase project and register a Web App.\n2. Enable Email/Password in Authentication.\n3. Create Firestore database and enable Storage.\n4. Paste the Web App config into firebase-config.js.\n5. Publish firestore.rules and storage.rules in Firebase Console.\n6. Add the deployed Vercel domain to Firebase authorised domains.\n\nNever put service-account keys in frontend files. This first release still needs a full inbox, realtime chat, synced favourites, reporting/moderation, admin dashboard, notifications and security testing. Have an adult review legal/privacy/safety requirements before public launch.\n
